# Research: Forge Portal

## Decision: Vite + React + TypeScript

Chosen for fast DX, typed contracts around `ProvisioningPort`, and Spec Kit-friendly incremental tasks.

## Decision: Mock-first ProvisioningPort

Backend for claims is still undecided by the product owner. Interface + mock unlocks UI delivery; GitHub Actions adapter preserves the existing POC path.

## Decision: Visual direction

Light cool gray-blue gradient + teal accent + IBM Plex Sans / IBM Plex Mono. Avoids prior purple dark theme and common AI aesthetic defaults.

## Decision: Brand name Forge

Short, memorable, hero-level on Catalog landing.
